# Support

Thanks for using Keypress Notifications. Pick the channel that fits your question.

| I want to… | Go to |
| --- | --- |
| Report a bug or request a feature | [Open an issue](https://github.com/Vijay431/keypress-notifications/issues/new/choose) |
| Ask a question or discuss an idea | [GitHub Discussions](https://github.com/Vijay431/keypress-notifications/discussions) |
| Report a security vulnerability | [Private advisory](https://github.com/Vijay431/keypress-notifications/security/advisories/new). See [SECURITY.md](SECURITY.md) |
| Contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before opening an issue, search existing issues and include your extension version, VS Code version, and operating system.
